# Interactive Puzzle Game - Java

A Java-based interactive puzzle game developed as part of my Advanced Programming coursework at Al Hussein Technical University (HTU).

## About the Project

The game challenges the user to solve scrambled words from different categories. The player selects a category, receives a scrambled word, and attempts to guess the correct answer.

## Game Categories

- Foods (Easy)
- Anime (Hard)
- Coding (Middle)
- Games (Very Hard)

## Programming Concepts

This project demonstrates different programming paradigms and concepts:

- Procedural Programming
- Object-Oriented Programming (OOP)
- Event-Driven Programming
- Java Swing GUI
- ArrayLists
- Inheritance
- Encapsulation
- Polymorphism
- Event Listeners
- Bubble Sort Algorithm

## Main Classes

- `Main.java` - Main entry point of the application
- `ArrayListPazzly.java` - Manages the puzzle word lists
- `WordRandom.java` - Handles word randomization
- `ChooseStyleTheGame.java` - Handles game category selection
- `GameLogic.java` - Controls the game logic
